❌ OLD WAY: Manual Sizes with Media Queries

How it works: You manually calculate breakpoints and tell the browser exactly how wide the image will be at each screen size.
<img srcset="banner-400.jpg 400w, banner-800.jpg 800w, banner-1200.jpg 1200w" sizes="(max-width: 600px) 100vw, (max-width: 1024px) 50vw, 1200px" src="banner-800.jpg" alt="Banner" loading="lazy" />

Live Demo:

Resize your browser window to see different images load

Problems:

  • ❌ Must predict exact layout at each breakpoint
  • ❌ If CSS changes, sizes are wrong
  • ❌ Complex to calculate and maintain
  • ❌ Easy to make mistakes
  • ❌ Doesn't work well with dynamic layouts
