Problems with this approach:
  • Had to manually calculate breakpoints
  • If CSS layout changes, sizes become wrong
  • Complex to maintain
  • Easy to make mistakes

✅ NEW WAY: sizes: auto (Automatic)

<img srcset="banner-400.jpg 400w, banner-800.jpg 800w, banner-1200.jpg 1200w" sizes="auto" src="banner-800.jpg" alt="Banner" loading="lazy" />

Benefits of sizes: auto:
  • ✅ Browser automatically detects rendered size
  • ✅ Adapts instantly when window resizes
  • ✅ Works with any CSS layout
  • ✅ Simple & maintenance-free
  • ✅ Always picks the optimal image
